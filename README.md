# AWS S3 Static Website Deployment

A static website deployed using Amazon S3 Static Website Hosting as part of my Cloud Computing Internship.

## Project Overview

The objective of this project was to host a static website using Amazon S3 and make it publicly accessible through an AWS-generated website endpoint.

## Technologies Used

- HTML
- CSS
- JavaScript
- Amazon S3
- AWS Management Console

## Architecture

Local Website
↓
Amazon S3 Bucket
↓
Upload HTML/CSS/JS Files
↓
Configure Public Access
↓
Bucket Policy
↓
Static Website Hosting
↓
Public Website

## Workflow

1. Created an Amazon S3 bucket.
2. Uploaded HTML, CSS and JavaScript files.
3. Configured public access settings.
4. Added the required bucket policy.
5. Enabled static website hosting.
6. Configured the index document.
7. Tested the website using the public S3 endpoint.

## Project Files

- `index.html` - Main webpage
- `style.css` - Website styling
- `script.js` - JavaScript functionality
